# 🌐 ASE Club Website

A simple and user-friendly **ASE Club Website** developed using **HTML, CSS, and JavaScript**.

The website provides information about the club, its members, and other basic club-related details. It also includes a simple login interface created using JavaScript.

---

## 📌 Project Overview

The EAC Club Website is a basic frontend web project designed to provide visitors with information about the club.

The website includes multiple pages that allow users to explore the club, learn about it, and view its members.

---

## ✨ Features

### 🏠 Home Page

Provides an introduction to the EAC Club and serves as the main landing page of the website.

### ℹ️ About Page

Provides information about the club, its purpose, activities, and objectives.

### 👥 Members Page

Displays information about the members of the EAC Club.

### 🔐 Login System

Includes a basic login interface created using JavaScript.

> **Note:** The login system is implemented only on the frontend and is for demonstration purposes. No backend authentication or database is connected.

### 🎨 User Interface

The website uses CSS to create a clean and simple user interface with easy navigation between pages.

---

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the website
- **CSS3** – Used for styling and page layout
- **JavaScript** – Used for basic interactivity and login functionality

---

## 🚀 How to Run

No backend or database is required to run this project.

### Option 1: Open Directly

1. Download or clone the repository.
2. Open the project in VS Code.
3. Open the main HTML file in a web browser.

### Option 2: Using VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click the main HTML file.
4. Select **Open with Live Server**.

The website will open in your browser.
